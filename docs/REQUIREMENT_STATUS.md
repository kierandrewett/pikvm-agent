## Current verification boundary

The completed post-change selection is recorded in
[`../bench/README.md`](../bench/README.md). This restricted runner still hangs
in several static/screenshot/temp-file ASGI tests and cannot start the required
Docker/VM path for the next OSWorld iteration. A minimal probe also proves that
`asyncio.to_thread` cannot return reliably in this runner, so remaining
threaded vision cases are recorded as not run rather than inferred passes.
PaddleOCR no longer uses that seam: its native worker is process-isolated and
passed a bounded five-case lifecycle diagnostic, but the full hybrid accuracy
run remains outstanding.

The product is therefore **not complete**. The next release-critical work is:

1. make the Windows seven-trial loop pass repeatedly;
2. execute the full hybrid OCR and live field-crop passes, then raise ambiguous
   numeric/punctuation exactness;
3. run a frozen-code, larger public benchmark matrix;
4. obtain a supported Gemini OAuth/API path, repeat the managed Codex, Claude,
   and OpenCode clients on real tasks, and complete multi-hour UI streaming;
5. build the signed local operator package before starting hosted control-plane
   work.
